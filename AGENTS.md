# Howl project notes

Howl is a social app for NC State students to share short posts about campus life. The current app is intentionally plain and unstyled.

Use the `explorations/` folder for numbered design rounds (`01`, `02`, `03`, and so on). Keep experiments there; do not change the real app while exploring.

The project owner is a beginner and does not use the terminal. Prefer clear, simple changes and explain any steps that require commands.
